# 鏡頭曝光設定

`ov02c10_scan.json` 是掃碼用的影像處理設定（esp_ipa）。
從 `components/ov02c10/cfg/ov02c10_default_p4_eco4.json` 複製，只改 `agc.luma_adjust`：

| 欄位 | 原值 | 新值 | 原因 |
|---|---|---|---|
| `weight`（5x5 測光權重） | 中央 5、外圈 1 | 中央 8、中間一圈 2–4、最外圈 0 | 手機螢幕在畫面中央，比周圍亮很多。以中央為準，條碼的細線才不會被白色蓋掉 |
| `target_low`／`target`／`target_high` | 48／75／85 | 40／50／60 | 比預設暗一點，保留亮部細節；容許範圍縮窄，曝光更貼近目標。20／30／40 時螢幕較暗的手機掃不出來（2026-11-23 實測，自動曝光已開啟） |
| `high_regions` | 3 | 1 | 過亮（超過 `high_threshold`）的格子少於這個數時，那幾格不算進測光。手機螢幕通常只佔 1～2 格，會被排除，曝光只看周圍較暗的手與背景，反而把螢幕拉得更亮。設成 1 就不排除 |

這個檔案適用晶片版本低於 v3 的 ESP32-P4（板上是 v1.3）。`tools/check_ipa_json.py` 會檢查權重。

**必須開啟 `CONFIG_ESP_VIDEO_ENABLE_ISP_PIPELINE_CONTROLLER`，這份設定才有作用。** 它關著時沒有自動曝光，鏡頭停在初始曝光值，手機螢幕一定過曝。
`sdkconfig.defaults` 有寫 `=y`，但 `sdkconfig` 裡已經寫了「not set」時，defaults 不會生效。
2026-11-23 第一塊板子就是這樣：上表 40／60／72 等數值都是在自動曝光沒運作時調的，等於沒有作用。
開啟後用 20／30／40、`high_regions` 1 實測可以讀到亮的手機螢幕，但暗的螢幕讀不到，所以改成 40／50／60。
確認方法：開機 log 要有 `ov02c10: set exposure 0x...`。沒有這行就是自動曝光沒在跑。

試過但沒用：`aen.contrast` 拉高到 170～180（原本 126～132），暗螢幕反而更讀不到（2026-11-23），已改回。
